📈 StockSentinel — public dataset

Daily-updated stock prices, FinBERT news sentiment and XGBoost forecasts for AMZN, GOOGL and MSFT. Built with GitHub Actions; served by GitHub Pages.

  • manifest.json — freshness metadata
  • prices_latest.json — last 30 days of prices
  • predictions_latest.json — next-day forecasts
  • news_latest.json — recent news with sentiment
  • history/prices_history.csv · news_history.ndjson · predictions_history.csv
Academic project — not investment advice. Source on GitHub · Frontend
